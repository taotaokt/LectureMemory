# Changelog

All notable changes to Lecture Memory are documented here.

## [0.1.0] - 2026-10-02

### Added

- Course, lecture, slide-page, note, and normalized concept persistence.
- Validated PDF ingestion with page rendering and text-layer extraction.
- Qwen3-VL slide, note, and query embeddings with a content-addressed cache.
- Persistent FAISS indexing with model, dimension, and source-freshness metadata.
- Course-scoped multimodal retrieval, optional Qwen reranking, and weighted rank fusion.
- Streamlit workflows for course creation, PDF upload, slide browsing, note editing, indexing,
  and natural-language search.
- A reproducible 50-query bilingual benchmark with BM25, embedding, reranking, quality, and
  latency evaluation.
- A synthetic public demo workspace generated by `python -m scripts.prepare_demo`.
- GitHub Actions checks for Ruff and the complete automated test suite.

### Quality

- 329 automated tests passed before release preparation.
- Real-browser acceptance covered course navigation, index status, fast search, result cards,
  and lecture detail pages.
- A real 116-page local index rebuild reused all cached vectors and passed freshness validation.

### Known limitations

- The optional embedding and reranking models require substantial local disk and memory.
- First model use may download several gigabytes from Hugging Face.
- Reranked search is considerably slower than embedding-only search on Apple Silicon.
- Index refresh is explicit rather than automatic after source changes.
- Concept extraction uses a conservative local rule-based baseline.
