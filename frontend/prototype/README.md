# Lecture Memory UI prototype

This directory contains the current interactive product prototype for Lecture Memory.

Open `lecture-memory-prototype.html` in a browser to review the flows for:

- learning dashboard and global search;
- course lecture lists and guided empty states;
- three-column lecture reading and page-linked notes;
- search results, filtering, preview, and no-result recovery;
- staged PDF processing, failure details, and retry;
- one-second note autosave with saving, saved, failed, and retry states;
- responsive slide/note switching on smaller screens.

This prototype is self-contained and does not call or modify the backend.
